# LipatoS - Запрет изменения валюты

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который запрещает обычным игрокам вручную изменять значения валюты в карточке персонажа.

При этом поля не переводятся в `readonly` или `disabled`, поэтому стандартный внешний вид валюты D&D 5e сохраняется без затемнения.

## Версия

**2.0.0**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0–6.0.1**

## Возможности

- запрещает обычным игрокам вручную изменять количество валюты;
- блокирует ввод с клавиатуры, вставку, перетаскивание, изменение полей и колесо мыши;
- показывает предупреждение **«Изменять валюту вручную может только ГМ.»**;
- не использует `readonly` или `disabled`, поэтому внешний вид валюты остаётся стандартным;
- автоматическое получение валюты продолжает работать;
- передача валюты между персонажами продолжает работать;
- совместим с автоматическими механиками вроде Gatherer, которые изменяют валюту через обновление данных;
- ГМ и Assistant GM работают без ограничений.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-player-currency-lock/main/module.json`
